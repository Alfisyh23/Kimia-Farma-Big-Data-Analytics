# Kimia Farma Big Data Analytics (2020-2023)

## 📌 Project Overview
Project ini bertujuan untuk menganalisis performa bisnis, penjualan, laba bersih, serta rating cabang Kimia Farma periode 2020-2023. Data diolah menggunakan Google BigQuery dan divisualisasikan secara interaktif melalui Looker Studio.

## 🛠️ Tools & Technologies Used
* **Database & Data Warehouse**: Google BigQuery (SQL)
* **Data Visualization**: Google Looker Studio
* **Version Control**: GitHub

## 📊 Key Insights & Dashboards
- **Total Sales & Profit**: Menampilkan ringkasan kinerja keuangan perusahaan.
- **Top 5 Branch Performance**: Analisis perbandingan cabang dengan rating tertinggi vs transaksi terendah.
- **Discount Impact Analysis**: Menilai dampak persentase diskon terhadap volume transaksi dan penjualan.
